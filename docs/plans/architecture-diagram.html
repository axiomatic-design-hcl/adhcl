07

Verification

A scenario is a list of steps that tests one criterion. A scenario is a plan. It is not a test result.

CriterionScenarioKindResult
fr.accept_scan.criterion.digit_countscenario.scan_digitsoperationalNo recorded result
fr.count_pallet.criterion.exact_countscenario.batch_countsoperationalNo recorded result
scenario.scan_digits Covers the digit rule at the accepted length and at the lengths around it.
  1. Submit a scan with twelve digits and expect it to be accepted.
  2. Submit scans with eleven digits, thirteen digits, and letters. Expect a rejection for each.
  3. Expect no accepted scan from any rejected input.
scenario.batch_counts Covers a batch with a rejected scan and an empty batch.
  1. Submit three accepted scans and one rejected scan to one batch.
  2. Expect the returned count to be 3.
  3. Submit an empty batch and expect the returned count to be 0.
